# atcoder-ts-set

Using TypeScript Package For Atcoder.

## Env

- [node v20.11.0 or more](https://nodejs.org/api/)
  - [yarn 1.22.21 or more](https://classic.yarnpkg.com/en/docs/install#windows-stable)

## Commands

```bash
# setup (arg: problem id)
yarn setup ${problem-id}

## example

yarn setup a
yarn setup b
yarn setup c
yarn setup d
yarn setup e
yarn setup f

# test

yarn test
```
